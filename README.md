# Escuela Webster — Misión Vida Saludable

Proyecto de Matemáticas III, 14 días. Juego HTML sin dependencias externas ni servidores de datos.

## Publicación en GitHub Pages
1. Crea un repositorio público (por ejemplo, `mision-vida-saludable`).
2. Sube `index.html` en la raíz del repositorio.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. Visita `https://TU-USUARIO.github.io/mision-vida-saludable/`.

## Advertencias
- Los valores nutricionales y los costos son inventados con fines didácticos; NO son recomendaciones dietéticas ni permiten evaluar una dieta real.
- La puntuación es un índice pedagógico; NO permite predecir niveles de glucosa, presión arterial o el desarrollo de enfermedades.
- Solo utiliza adultos y datos ficticios. Los datos se guardan en localStorage del dispositivo.
- Exporta el respaldo JSON si cambias de dispositivo o navegador; exporta CSV para Excel.
- Se aconseja evaluar la investigación, no la puntuación del juego.

Referencias: Organización Mundial de la Salud (dieta saludable y actividad física) y CDC (sueño de adultos). Los enlaces están en la pestaña Fuentes del juego.
